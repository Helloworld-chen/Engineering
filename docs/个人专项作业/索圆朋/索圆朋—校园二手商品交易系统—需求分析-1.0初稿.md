# 阶段1.0 自主初析（单人任务）

## 1.1 核心功能需求（简要列举）

1. 买家申请退款（已付款、卖家未发货）。

2. 卖家审核退款申请。

3. 卖家超时未处理时，系统自动退款。

4. 买家提交投诉（已收货、平台未结算）。

5. 买家寄回商品，卖家验收后退款。

6. 处理结果通知买卖双方。

## 1.2 质量需求（初步设想）

性能：页面和列表打开速度可接受，不出现明显卡顿。

安全性：用户只能操作自己的订单，不能越权查看他人订单。

可靠性：数据不丢失，服务重启后订单状态正确。

## 1.3 开发约束

团队 4 人，每人负责 2 个功能模块，开发周期约 6 周。

支付、物流、统一身份认证均不接入，使用模拟数据。

代码托管在 GitHub，团队协作开发。

## 1.4 自我反思（可选）

超时功能的实现方式还不清楚。

退款的具体执行过程（资金如何退回、如何避免重复退款）尚未想清楚。

客服在售后流程中的职责范围还不是很明确。
