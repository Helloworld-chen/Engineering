## 环境与隔离

- macOS 26.5.2（25F84）；Playwright 1.65.0、Chromium 158.0.8127.18、axe-core 4.14.0。
- 前端为 Vue 3 / TypeScript / Element Plus，后端为 Java 21 / Spring Boot，数据库 MySQL 8.4。
- 宿主测试工具实际运行于 Node 25.8.1；项目推荐 Node 24，最终 Docker 静态构建使用 Node 24，并对该构建运行完整浏览器验收。
- 最终验收地址 http://127.0.0.1:15180 ，Compose 项目 `campus-market-a11y` 使用独立数据库卷和上传卷。原有 5173 网站及其数据未作为测试目标。
- 交易使用演示提供者和模拟余额。测试会生成商品、订单、评价并推进演示时钟；截图中的业务时间可能与电脑时间不同。

## 发现与修复

1. 初始专项12项中11项失败、1项通过。记录暴露了标题/焦点、移动菜单背景隔离、错误状态清除、图片移除名称、强制颜色边框、演示说明区域语义等问题。此初始脚本还使用了不能准确排除 inert 元素的 Playwright角色查询，因此失败数量不能直接当作真实缺陷数量。
2. 背景隔离验证改为读取 Chromium DevTools Protocol 的实际可访问树，并尝试聚焦背景；避免只依赖DOM角色查询。弹窗开闭动画结束后再扫描，避免过渡透明度导致的临时对比度误报。
3. 检查 axe 的 incomplete 项时发现分类容器和默认头像缺少支持名称的角色，分别补 group、img，并加入回归断言。
4. 开发环境完整回归曾出现1项物流即时通知失败，原始日志保留。该轮运行期间发生前端热更新，故最终验收改为冻结后的 Docker 静态构建，未通过放宽断言或隐藏失败处理。

## 验证边界

- **真实读屏兼容性尚待补测。** 经用户授权临时开启 macOS VoiceOver，系统开关曾显示开启，但未取得可核验的朗读输出；未计入通过记录。测试后已核实开关关闭。Windows + NVDA 未测试。
- forced-colors 来自 Chromium 媒体特性模拟，未覆盖 Windows 实际高对比度主题；200%采用文本字号及行高放大，未等同于浏览器整体缩放。
- 键盘交易测试通过Tab、Enter、方向键操作业务控件；账号登录和商品准备使用自动化/API。上传控件先验证键盘可达，再通过 setInputFiles 注入文件，未验证操作系统原生文件选择器。
- axe 检查的是所访问状态及所启用规则。零违规不构成完整WCAG认证，也不代替听读体验验证。
- 验收版使用独立演示数据，未把真实用户个人资料、真实交易或原网站数据移入证据目录。

启动、测试命令和人工读屏复测步骤详见仓库 `docs/accessibility.md`。
