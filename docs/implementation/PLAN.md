# M01 / M02 实施计划
依据：陈玉豪需求 V1.2、架构 V1.1，用户于2026-11-07批准的编码计划。
## Task 1: 工程与接口骨架
单体后端 Java21/Boot4.1.2/MyBatis4/MySQL8.4；Vue3/TS前端。共享事务、身份、时间、幂等、事件。队友按模块可替换演示适配。
## Task 2: 页面结构及公共组件
landing-page-design；黑白灰工具风，统一状态/反馈/上传/倒计时，商品、订单、售后关键页及所有M01页面。
## Task 3: 下单付款
2分钟截止、唯一商品占用、取消超时、原子资金及流水、请求幂等、失败回滚。
## Task 4: 履约结算
发货10秒送达，48小时收货，主动自动共用结算；重复任务和代次校验。
## Task 5: 售后及全站适配
暂停恢复、原额退款、退货10秒及24小时验收；队友接口、持久化演示状态和契约测试。
## Task 6: 验证交付
JUnit真实MySQL/Vitest/Playwright；T01-T26映射；接口/运行/接入文档，架构V1.2，本地状态，只提交本次变更，不推送。
## 已批准默认
