## 本轮已确认的规则

以下是AI协作过程中经学生明确确认的规则，拟写入下一版需求时使用【VP-Adopted】标记，不表示已修改GitHub上的初稿。

1. 一条商品信息支持多件库存，买家每笔订单可以选择购买数量。【VP-Adopted】
2. 买家提交申请时暂不占用库存；卖家接受时检查并占用对应数量，剩余可购买数量仍可供其他申请使用。【VP-Adopted】
3. 商品名称、描述或图片修改后重新审核，审核期间暂停公开展示和新购买申请，通过后恢复展示与符合条件的出售；已有订单保留原成交信息。【VP-Adopted】
4. 注册必填登录名、密码、确认密码；确认密码只用于校验，不保存。昵称在个人资料中填写，暂不收集学号、手机号，不接入外部身份认证。【VP-Adopted】
5. 接受申请时若库存不足，整份接受失败，不能自动减少购买数量或部分成交。【VP-Adopted】

## 已确认的取舍理由

- **库存占用时点：**AI提出理由后，学生明确认可：未被卖家接受的申请不提前占用库存，可减少对其他买家的影响，并控制本次开发和测试范围。这不免除已接受订单取消或超时后的库存释放需求。
- **商品修改后的审核：**学生选择暂停出售并重新审核，直接给出的理由为“简化代码”。未选择保留旧版继续出售的方案，以减少同时维护两套商品内容的复杂度。

- 多件库存下，部分数量被占用或售出时的改价、内容修改、库存调整和下架规则；价格变化是否需要重新审核。
