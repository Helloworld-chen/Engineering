## 四 与初稿的主要变化

1. 将多件库存、购买数量、卖家接受时占用和库存不足整份失败写成明确规则。
2. 明确名称、描述、图片、单价变化后的重审和隐藏要求，保留原订单成交信息。
3. 明确注册、密码、会话、昵称与图片输入边界。
4. 明确占用期间维护限制、售罄限制及本期不做手动补货。
5. 将“不能超卖”“重启后数据还在”“响应要快”等目标转成具体场景和指标，生成TC-01～TC-21及N-L01～N-L06。
6. 保留L01～L09功能编号，给出需求与用例对应；实现文件和测试结果在开发阶段补充。
