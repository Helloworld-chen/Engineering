负责人：陈玉豪。需求版本：V1.3。更新日期：2026年11月10日。

本清单对应[个人需求分析V1.2](需求分析历史迭代稿/陈玉豪—校园二手商品交易系统—需求分析-终稿.docx)，覆盖 M01 项目前端与交互、M02 交易履约与资金结算。保留C01至C09，新增C10与C11；本清单V1.3记录已确认变更，原需求分析V1.2文档作为基线保留。清单记录当前功能要求；功能实现及 CodeArts 工作项状态须按实际开发结果核验，目前尚未录入工作项编号。

## 当前业务流程

卖家设置价格并上架商品 → 买家直接下单 → 创建待付款订单并锁定商品 → 买家在2分钟内模拟付款 → 平台暂管货款 → 卖家提交凭证并确认发货 → 10秒后系统自动登记送达 → 买家确认收货或无争议时48小时收货倒计时届满 → 向卖家结算。

客服支持退货退款 → 买家提交退货凭证并确认寄出 → 10秒后系统自动登记退货送达 → 启动卖家24小时验收期 → 卖家确认退货后退款；验收超时或存在异议时转交客服，货款继续暂管。

发货、退货的10秒计时均由后端执行，从对应提交成功时开始，使用统一业务时钟。正常运行按实际经过时间推进，测试时可推进时钟；刷新、关闭页面和重复请求均不得重置期限。物流送达后，仍需满足确认收货或退货验收条件，才能结算或退款。

## M01 项目前端与交互

### C01 用户按身份访问页面和操作入口

- 功能：提供注册、登录、退出、商品浏览与维护、订单及管理页面；按买家、卖家、管理员、客服的权限显示操作入口。
- 验收：买家可从在售商品页面直接进入下单付款；卖家查看已付款订单并发货；管理员使用商品审核及举报处理入口；后端复核操作权限。
- 对应团队需求：FR-01 至 FR-07、FR-11；购买入口按本次修订衔接 C05。

- V1.3变更：登录用户通过商品、订单、举报或售后上下文查看相关用户资料；服务端复核角色、业务权限与目标用户关系。管理员和客服不获得任意用户搜索、账户余额和无关私人订单权限。

### C02 用户获得表单校验与操作反馈

- 功能：标明必填字段；指出缺失或格式错误的具体输入；显示读取数据、提交请求、无结果、成功及失败提示。
- 验收：错误提示指出字段或业务条件；操作成功后，页面显示后端返回或重新查询的商品、订单、售后单及货款状态。
- 对应团队需求：NFR-09。

### C03 用户查看业务期限与最新处理进度

- 功能：显示付款、确认收货、退款审核、申诉或退货验收的剩余时间；刷新或重连后重新查询订单、售后单和通知。
- 验收：倒计时以后台保存的业务时间和截止时刻为准；收货计时暂停时显示已暂停及剩余时间；商品及退货自动送达后，页面查询结果与后端一致，刷新不重置任何期限。
- 对应团队需求：FR-24、FR-25、AR-01。

### C04 用户通过页面办理售后并查询结果

- 功能：提供退款、申诉、送达后投诉、退货凭证提交及确认寄出入口，以及卖家审核、退货验收和客服处理页面。
- 验收：展示售后单当前处理环节、理由及关联货款的暂管、已退款或已结算状态；买家确认退货寄出后展示运输进度，系统登记退货送达后展示验收进度。
- 对应团队需求：FR-15 至 FR-23。

- V1.3变更：客服从有权处理的售后查看双方基本资料、公开信用及对应申请和处理历史，并通过原授权订单查看物流凭证；返回保留来源筛选与页码。

## M02 交易履约与资金结算

### C05 买家直接下单并在期限内付款

- 功能：买家按卖家设定的商品价格直接下单。后端校验买家身份和商品可购买状态，创建待付款订单、记录订单金额并锁定商品，给予2分钟付款期限。
- 验收：整个下单流程无需卖家接受购买申请；同一商品同时最多一个有效待付款订单；其他买家下单时收到已锁定或已售出提示。付款前主动取消或超时未付时关闭订单并解除商品锁定。重复提交不得创建多个有效订单。
- 对应团队需求：FR-08、FR-09。原购买申请排队及卖家接受流程按本次直接下单规则修订。

### C06 买家完成模拟付款并由平台暂管货款

- 功能：核验订单买家、金额、余额和付款期限，完成模拟扣款、资金流水记录及平台暂管记录。
- 验收：付款成功后商品已售出、订单待发货；同一商品不得再次下单成交。余额不足或期限已过时不扣款；重复付款不得重复扣款；扣款、暂管和商品售出标记一并生效。
- 对应团队需求：FR-10。

### C07 买卖双方查询订单及卖家提交发货凭证

- 功能：买卖双方查询本人订单的金额、付款、物流、售后和剩余期限；卖家上传商品及包装照片、填写模拟物流单号并确认发货。
- 验收：凭证关联当前订单并记录提交时间；仅在订单已付款且无发货限制时允许发货。确认发货成功后，物流进入运输中，并启动10秒送达计时。
- 对应团队需求：FR-11、FR-12。

- V1.3变更：订单详情提供双方资料入口；完成且结算后显示评价资格、截止时间、本人评价与公开评价。工作人员只读查看公开评价。

### C08 系统自动登记物流送达并完成收货结算

- 功能：后端从卖家确认发货成功时起计时10秒，到期自动将物流改为已送达并记录送达时间；从送达时间起启动48小时收货期限。
- 验收：未满10秒时仍为运输中，满10秒自动送达，无需管理员登记。商品已送达且无待处理争议时允许买家主动确认收货；收货倒计时届满时自动确认并结算。送达本身不触发结算，同一订单只结算一次；刷新或重复发货、送达事件不得重置期限。
- 对应团队需求：FR-13、FR-14。原管理员登记送达流程按本次自动模拟物流规则修订。

### C09 根据售后结果处理订单与退款

- 功能：M07 受理发货前退款后暂停发货和结算，退款获准后退回暂管货款并关闭订单。送达后投诉受理时暂停自动收货计时和结算，驳回后恢复暂停前剩余时间。
- 退货流程：客服支持退货退款后，买家上传凭证并确认寄出；提交成功10秒后，后端自动登记退货送达并启动卖家24小时验收期。
- 验收：卖家确认退货后才退回原订单暂管款项并关闭订单，退货运费不计入退款；验收超时或提出异议时转交客服，货款继续暂管。退货送达本身不触发退款；重复事件不得重复退款或重置验收期限。
- 对应团队需求：FR-15 至 FR-23；退货送达采用本次确认的10秒自动模拟规则。

## V1.3新增需求

### C10 用户资料查看与维护

- 操作主体：普通用户维护本人头像、昵称、学校、校区、个人简介及选填性别；交易相关用户、管理员和客服按具体业务关系查看资料。
- 展示：未填字段显示“未填写”，无头像使用默认图；分别展示买家与卖家信用、公开评价、审核通过且在售或已售商品。商品和评价每页20条，筛选与页码写入地址，返回原业务位置。
- 权限：商品限发布者；订单限参与双方；举报仅有权管理员查看举报人及商品发布者；售后仅授权参与者或客服查看双方。每个资料及分页请求重新验证上下文。本人查看本人资料可不传上下文。
- 验收：头像须本人上传、图片合格且用途正确；当前头像登录可读，替换后的旧头像仅所有者可读；资料失败有错误与重试，切换账号清空旧数据。无联系方式、IP定位、认证、关注、粉丝或动态。
- 变更编号：CR-CYH-01、CR-CYH-03。M01实现页面，身份模块协作提供资料与授权。

### C11 交易评价与信用展示

- 资格：仅交易完成且货款已结算的订单，双方从实际结算时间起7天内各提交一次整数1—5星和1—500字文字；提交前确认，提交后不可修改或删除。取消、退款、未完成及缺少可信结算记录的订单不能评价。
- 公开：双方均提交时同一事务公开；期限到达时公开已有评价；未评价不生成评分。公开前只有作者可看本人内容，交易对方、工作人员和其他查看者不能读取。
- 信用：买家给出的评价计入卖家信用，卖家给出的评价计入买家信用。仅统计已公开评价，从首条公开评价起定级；无评价显示“暂无评价”。同时显示平均星级、数量与1—5星分布。
- 等级：平均值四舍五入保留两位小数，再按展示值分级；4.50—5.00优秀、4.00—4.49良好、3.00—3.99一般、低于3.00待提升。
- 隐私与同步：公开列表仅含评价者昵称和身份、星级、文字、公开时间、商品标题，不公开私人订单编号、金额或凭证。公开时通知双方；未公开提交仅静默刷新提交者。
- 历史与恢复：历史订单沿用原结算流水时间，不重新赠送期限；持久化任务支持停机恢复、重试和并发，demo/real一致，无虚构资料或评价。
- 变更编号：CR-CYH-02。M02衔接结算，M01展示，M08协作提供期限和通知。
