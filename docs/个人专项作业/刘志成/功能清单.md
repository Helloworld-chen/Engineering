# 刘志成个人功能清单

负责人：刘志成。需求版本：V1.1。更新日期：2026年11月5日。

本清单对应[个人需求分析](刘志成—校园二手商品交易系统—需求分析.docx)，覆盖 M05 商品浏览检索、M06 商品审核与举报处理。Z01 至 Z09 为个人需求编号。清单记录当前功能要求；功能实现及 CodeArts 工作项状态须按实际开发结果核验，目前尚未录入工作项编号。

## 当前业务流程

卖家发布商品并设定价格 → 商品进入待审核 → 管理员审核，给出通过或驳回结论与理由 → 通过后在售并进入公开列表 → 买家在商品页直接下单，M02 在自身事务内校验可购买状态并锁定商品 → 付款成功后商品标记已售出。M05 只负责列表展示与检索口径，不参与该事务。

商品在售期间，买家可对公开商品提交违规举报 → 管理员核查并记录结论 → 确认违规时经 M04 下架商品，已有订单与交易记录继续保留。

审核与处置均使用商品内容版本进行校验：管理员提交的结论只能对应其读取到的内容版本，卖家在审核期间修改商品会导致本次审核作废并需重新读取。商品状态由 M04 统一写入，M05 只读取、只展示，M06 只保存结论。

## M05 商品浏览检索

### Z01 商品列表与详情

- 功能：公开列表与详情仅展示审核通过且在售的商品，显示名称、价格、描述、图片与可购买状态；待审核、已驳回、违规下架的商品不进入公开结果；已售出商品保留可查询的成交状态说明。
- 验收：以驳回、下架、已售出三种商品分别请求列表与详情，均不出现购买入口；已售出详情返回成交状态而非 404。
- 对应团队需求：FR-05。

### Z02 检索与分页

- 功能：支持按关键词与分类筛选，按稳定顺序分页；无匹配结果时返回空集合与明确提示；响应回传查询条件与分页信息，便于页面保持查询状态。
- 验收：同一查询重复执行结果顺序一致；翻页不重复不遗漏；空结果与非法页码返回可识别提示。
- 对应团队需求：FR-05 细化。

### Z03 可购买状态只读展示

- 功能：列表与详情返回商品当前的出售状态与占用情况，页面据此显示「可购买 / 已锁定（剩余秒数）/ 已售出」，不可购买时给出原因文案。判定与下单校验由 M02 在其事务内完成，本模块不提供校验接口、不参与加锁。
- 验收：九种原因码均可构造并命中；返回版本与商品当前版本一致；M02 未调用本接口时下单应被拒绝；锁定到期后同一商品重新返回可购买。
- 对应团队需求：FR-08 的状态展示部分；判定由 M02 承担。

### Z04 可见性与可购买性判定规则

- 功能：商品对外可见且可购买，须同时满足「审核通过」与「出售状态为在售或已锁定」；已下架、已售出的商品不进入公开列表。审核通过、驳回、上架、下架、锁定、售出等状态迁移由 M04 商品主数据执行，本模块只声明判定所依赖的状态组合并对外提供判定结果。状态变更携带商品版本，旧版本审核结论不得覆盖新内容。
- 验收：构造「审核中卖家修改内容」场景，旧审核提交被拒绝；下架商品在列表与详情中均不可见；非法状态跳转由 M04 拒绝并记录原因；物流事件不得回写商品状态。
- 对应团队需求：FR-06 细化；V1.2 变更后补充。过滤口径归 M05，状态迁移的执行归 M04。

### Z05 分类与检索字段维护

- 功能：维护分类体系与可检索字段（名称、描述、分类）；分类调整只影响后续查询，不改变已提交订单所记录的商品快照。
- 验收：调整分类后已成交订单仍显示原分类；新增分类后列表可按新分类筛选。
- 对应团队需求：FR-05 细化。

## M06 商品审核与举报处理

### Z06 商品审核

- 功能：管理员查看待审核商品的内容、图片与当前版本，记录通过或驳回的结论与理由；驳回后卖家可修改并重提，重提生成新版本供再次审核。
- 验收：通过与驳回均产生审核记录；驳回必须填写理由；重提后版本递增且需重新审核；同一版本不产生第二条有效结论。
- 对应团队需求：FR-06。

### Z07 违规举报

- 功能：用户对公开商品提交商品号、举报理由与可选凭证图片，系统生成可查询的举报记录，记录举报人与提交时间。
- 验收：缺理由或商品号不存在时拒绝；同一用户对同一商品的有效举报去重；提交后可在本人举报列表查到。
- 对应团队需求：FR-07。

### Z08 举报处置

- 功能：管理员核查举报，记录「确认违规」或「不成立」的结论与理由；确认违规时经 M04 下架商品，已有订单与交易记录继续保留，不由举报流程裁定退款。
- 验收：处置后商品从公开列表消失；已有订单仍可查询与履约；结论与理由写入处置记录且只追加不覆盖。
- 对应团队需求：FR-07。

### Z09 权限与追踪

- 功能：普通用户不得执行审核与处置；举报人仅能查询本人举报；审核与处置记录保存操作人、时间、前后状态与理由，凭证访问按角色与归属限制。
- 验收：普通账号调用审核接口返回拒绝并记审计；他人举报查询返回拒绝；按商品版本可重建完整处置链。
- 对应团队需求：FR-02、FR-07、NFR-08。
