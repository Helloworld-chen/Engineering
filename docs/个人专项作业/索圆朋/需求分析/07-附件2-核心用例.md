# 附件2 核心用例描述

用例一：发货前退款与申诉

用例名称：发货前退款与申诉　　用例标识：UC-S1　　执行者：买家、卖家、客服

目标：买家在卖家未发货前取消交易并拿回货款；卖家拒绝时由客服裁决。

范围：校园二手商品交易系统——售后模块（M07）、资金模块（M02）、通知与时钟模块（M08）。

质量需求：订单与资金一致；期限计算准确；操作可审计。

前置条件：订单已付款、卖家未发货、平台未结算；该订单无进行中的售后单。

基本流程：

1. 买家提交退款申请并填写理由；M07 锁定订单，复查付款与发货状态，创建售后单并暂停发货与结算。

2. M08 生成卖家审核期限（24 小时），并通知卖家。

3. 卖家在期限内审核：同意则 M07 调用 M02 退款并关闭订单；拒绝则记录理由并开启买家申诉期。

4. 买家在申诉期内提出申诉，M07 将售后单转客服，订单保持冻结。

5. 客服查看双方说明与凭证，作出裁决并记录理由；符合退款条件时由 M07 指示 M02 执行退款，否则恢复订单为待发货。

扩展流程：

3a. 卖家超过 24 小时未处理：M08 到期任务将售后单转交客服。（对应 S03）

4a. 买家放弃申诉或申诉期届满未申诉：M07 恢复订单为待发货。

5a. 客服裁定不退款：订单恢复为待发货，平台继续暂管货款。

异常与结束结果：买家身份不符或订单已发货时，申请被拒绝并提示原因；同一请求重复提交只生效一次；任一环节失败则回滚本次修改，订单与资金保持原状。

对应需求：S01～S06、S13～S18。

用例二：送达后投诉与退货验收

用例名称：送达后投诉与退货验收　　用例标识：UC-S2　　执行者：买家、卖家、客服、管理员

目标：买家在收货后发现商品问题时能暂停结算并获得退货退款；验收异常有升级出口。

范围：售后模块（M07）、资金模块（M02）、通知与时钟模块（M08）。

质量需求：投诉时保存剩余收货时长；驳回后按剩余时长恢复；验收超时不自动退款。

前置条件：商品已送达买家、平台尚未结算；该订单无重复有效投诉。

基本流程：

1. 买家提交投诉并上传照片凭证；M07 保存剩余自动收货时长（不小于 0），暂停自动收货与结算。

2. 客服审核投诉：驳回则恢复剩余计时；支持退货则通知买家寄回。

3. 买家填写退货单号并上传凭证；管理员登记退货已送达卖家，M08 开始计算卖家 24 小时验收期限。

4. 卖家确认收回商品，M07 调用 M02 将暂管货款退回买家账户；系统通知双方。

扩展流程：

4a. 卖家超过 24 小时未验收：M08 到期任务将售后单转客服，平台继续暂管货款。

4b. 卖家提出退货异议：售后单转客服裁决。

2a. 客服驳回投诉：恢复剩余收货时长，重复驳回不再延长。

异常与结束结果：已结算后提交投诉被拒绝；重复登记送达不重复延长验收期限；通知重复投递不重复生成站内通知。

对应需求：S06～S09、S15～S17。
